# Проект 1С

Проект подготовлен для работы через Unica и GitHub.

- исходники конфигурации: `src/`;
- общая конфигурация v8-runner: `v8project.yaml`;
- локальный путь к информационной базе: `v8project.local.yaml`;
- результаты сборки и служебные данные: `build/` и `.build/`.

Файл `1Cv8.1CD` остаётся локальной рабочей базой и намеренно не попадает в Git.

## Первичная синхронизация

После проверки проекта выполните выгрузку конфигурации из базы в `src/`. При
последующих изменениях источником правды должен быть либо Git, либо база — не
смешивайте оба направления без явного решения.
